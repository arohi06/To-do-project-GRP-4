To-Do Application



A full-stack To-Do application designed to help users organize, manage, and track their daily tasks efficiently, built using modern web technologies.



\## Technology Stack



| Area | Technology |

|---|---|

| Frontend | Angular 20, TypeScript, SCSS |

| Backend | Node.js, Fastify |

| Database | PostgreSQL |

| Database Query Builder | Knex.js |

| Authentication | JWT, bcryptjs |

| Version Control | Git and GitHub |

\## Getting Started



1\. Install the prerequisites listed in \[SETUP.md](docs/SETUP.md).

2\. Clone this repository.

3\. Install frontend and backend dependencies.

4\. Configure the backend environment variables.

5\. Create the PostgreSQL database.

6\. Start the frontend and backend servers.



Refer to \[SETUP.md](docs/SETUP.md) for detailed instructions.
